# CSI3150-Assignment3-VinylVault
Dependencies:
Node.js ver: 24.22.0
NPM ver: 11.19.1
react-router-dom: 7.18.5

# How to install this project: 
1) Click the green "<> Code" button
2) Locate the "Download ZIP" button
3) click it and choose where you want it to download
4) after downloading, unzip it

# Installing React Router Dom:
1) Open the unzipped file
2) without clicking a file, right click in the blank space
3) locate and click the "open in terminal" option
4) copy & paste or type `npm install react-router-dom` in the terminal
5) press enter

# Running the project:
1) Open the unzipped file
2) without clicking a file, right click in the blank space
3) locate and click the "open in terminal" option
4) copy & paste or type `npm run dev` in the terminal
5) press enter
